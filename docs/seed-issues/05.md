# Add label-below-score input to apply a needs-detail label on low-scoring issues

## Context
In `src/issue-mode.ts` (`OctokitLike` at lines 17-41 and `runIssueMode` at lines 123-170), the action posts or updates the `<!-- waveforge -->` diagnostic comment and checks `failOnLowScore`, but cannot automatically apply or remove a triage label (such as `needs-detail`) when `report.score < inputs.minScore`. Adding an optional `label-below-score` string input lets maintainers filter under-specified issues directly in GitHub's issue list.

## Requirements
- Add optional input `label-below-score` (default `""`) to `action.yml` and `src/inputs.ts`.
- Extend `OctokitLike.rest.issues` in `src/issue-mode.ts` with `addLabels` and `removeLabel`.
- When `labelBelowScore` is non-empty and `inputs.comment` is `true`, add the label if `report.score < inputs.minScore`, or remove it if present when `report.score >= inputs.minScore`.

## Done when

- [ ] Unit tests in `src/issue-mode.test.ts` verify label addition, label removal on improved score, and no label calls when `label-below-score` is empty
