# Skip automated bot accounts and closed issues in issue mode

## Context
In `src/issue-mode.ts` (`IssueContextPayload` at lines 9-15 and `runIssueMode` at lines 95-114), the action currently lints every `issues` webhook payload regardless of whether the issue is already closed or was opened by an automated bot account (such as Dependabot or release automation). Updating `src/issue-mode.ts` and the `README.md` docs to skip closed issues and bot authors avoids unnecessary API calls and noise on automated issues.

## Requirements
- Extend `IssueContextPayload` in `src/issue-mode.ts` to read `issue.state` and `issue.user?.type`.
- Return early with an informational `core.info` log when `issue.state === "closed"` or `issue.user?.type === "Bot"`.
- Document the bot and closed-issue skip behavior in `README.md`.
