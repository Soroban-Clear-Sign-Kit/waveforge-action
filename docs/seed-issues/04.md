# Add dry-run input to preview comments and summaries without side effects

## Context
In `scripts/local-run.mjs` (lines 58-61), the local harness must manually override `INPUT_COMMENT=false` because `action.yml` and `src/inputs.ts` do not provide a `dry-run` boolean input. Adding a `dry-run` input allows workflows and local runs to compute outputs (`score`, `suggested-complexity`, `report-json`) and log the formatted Markdown report via `core.info` without creating or updating GitHub issue comments.

## Requirements
- Declare `dry-run` (boolean, default `"false"`) in `action.yml` and parse `dryRun` in `src/inputs.ts`.
- In `src/issue-mode.ts`, when `inputs.dryRun` is `true`, skip Octokit comment calls and log the rendered comment body with `core.info`.
- Update `scripts/local-run.mjs` and `README.md` inputs table to support `--dry-run`.
