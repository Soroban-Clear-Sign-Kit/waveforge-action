# Add GitHub Marketplace listing readiness checklist to docs

## Context
`action.yml` (lines 1-5) defines `name`, `description`, and `branding` (`icon: "check-circle"`, `color: "blue"`), and `docs/` tracks project decisions and progress, but the repository lacks a documented GitHub Marketplace pre-publish checklist verifying metadata, tag conventions, and security disclosures before publishing a release to the GitHub Marketplace.

## Requirements
- Create `docs/MARKETPLACE-CHECKLIST.md` covering required `action.yml` fields, `README.md` verification, and tag release steps (`v0.1.0` and floating `v1`).
- Link the checklist from `CONTRIBUTING.md`.
- Add a test in `src/action.test.ts` asserting `action.yml` `branding.icon` and `branding.color` are non-empty strings.

- [ ] `pnpm lint`, `pnpm typecheck`, and `pnpm test` pass cleanly
